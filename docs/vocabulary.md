# Определения

| Термин                        | Определение                                                                                                                                                                         |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Контекст редактора | Открытая сессия (как в VSC) - открытые документы, запущенные модули (как постоянный линтер или typst preview)         |
| Контекст документа | Содержимое файла с его метаданными<br />(например: путь к файлу; помеченные линтером участки текста, etc) |
