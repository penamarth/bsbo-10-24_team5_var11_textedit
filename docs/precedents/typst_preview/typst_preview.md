# Прецедент «Просмотр Typst-документа»

**Рамки.** Приложение «Текстовый редактор».

**Уровень.** Задача, определённая пользователем.

**Основной исполнитель.** Пользователь.

**Вспомогательный исполнитель.** Typst CLI.

### Заинтересованные лица и их требования

- **Пользователь.** Хочет просматривать результат обработки Typst-документа, не выходя из текстового редактора. Хочет видеть изменения итогового документа после редактирования исходного текста.
- **Typst CLI.** Получает исходный Typst-документ для обработки и возвращает результат компиляции или информацию об ошибках.

### Предусловия

Текстовый редактор запущен. Пользователем открыт или создан Typst-документ.

### Результаты (Постусловия)

- Исходный Typst-документ обработан.
- Результат обработки сохранён в контексте редактора.
- Пользователю отображён результат компиляции Typst-документа.

### Основной успешный сценарий

1. Пользователь вызывает функцию просмотра Typst-документа;
2. Система получает актуальное содержимое контекста документа из контекста редактора;
3. Система передаёт содержимое документа внешнему средству обработки Typst;
4. Внешнее средство выполняет компиляцию Typst-документа;
5. Система получает результат компиляции и обновляет контекст редактора, добавляя в него представление скомпилированного документа;
6. Модуль пользовательского интерфейса подхватывает изменение контекста редактора и отображает пользователю результат компиляции;
7. Пользователь продолжает редактирование исходного текста;
8. Система изменяет содержимое контекста документа и обновляет контекст редактора;
9. Модуль пользовательского интерфейса реагирует на изменение контекста и отображает пользователю изменённый исходный текст;
10. Система инициирует обновление предварительного просмотра с использованием актуального содержимого документа;
11. Результат повторной компиляции сохраняется в контексте редактора;
12. Модуль пользовательского интерфейса отображает обновлённое представление Typst-документа.

### Расширения (или альтернативные потоки)

**4а. При компиляции обнаружены ошибки.**

1. Внешнее средство обработки Typst возвращает информацию об ошибках компиляции.
2. Система обновляет контекст редактора, сохраняя полученную информацию.
3. Модуль пользовательского интерфейса отображает сообщение об ошибке.
4. Пользователь может исправить исходный текст и повторить компиляцию.

**4б. Внешнее средство обработки Typst недоступно.**

1. Система получает сообщение о невозможности выполнения компиляции.
2. Система обновляет контекст редактора.
3. Модуль пользовательского интерфейса уведомляет пользователя о невозможности предварительного просмотра.
4. Пользователь может продолжить редактирование исходного текста.

**7а. Пользователь закрывает предварительный просмотр.**

1. Система обновляет соответствующее состояние в контексте редактора.
2. Модуль пользовательского интерфейса прекращает отображение скомпилированного документа.
3. Содержимое контекста исходного документа остаётся без изменений.

### Специальные требования

- Предварительный просмотр должен отображать результат обработки актуального содержимого документа.
- Для просмотра несохранённых изменений не должно требоваться предварительное сохранение документа в файловую систему.
- Ошибки компиляции не должны препятствовать редактированию исходного текста.
- Пользователь должен иметь возможность просматривать исходный текст и результат его обработки.

### Список технологий и типов данных

- Модуль считывания взаимодействия пользователя с системой.
- Модуль взаимодействия с внешним средством обработки Typst.
- Модуль отображения состояния редактора пользователю.
- Typst CLI - внешнее средство компиляции документов.

### Частота использования

Регулярно при работе с Typst-документами.

- Должен ли предварительный просмотр обновляться автоматически при изменении исходного текста или только по запросу пользователя?
- Требуется ли сохранять результат компиляции в файловую систему?
- Необходимо ли обеспечить одновременное отображение исходного текста и результата компиляции?
