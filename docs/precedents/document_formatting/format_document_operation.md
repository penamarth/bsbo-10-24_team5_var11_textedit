# Описание операции formatDocument

**Операция:** `formatDocument()`.

**Ссылки:** прецедент [«Автоформатирование документа»](document_fomratting.md).

**Предусловия:** в контексте редактора есть активный открытый или созданный документ.

**Постусловия успешного выполнения:**

- Содержимому текущего документа присвоен отформатированный текст (модификация атрибута).
- Предыдущий текст доступен для отмены изменения.
- Файл на диске не изменён.
