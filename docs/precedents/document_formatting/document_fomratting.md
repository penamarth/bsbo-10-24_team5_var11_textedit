# Прецедент «Автоформатирование документа»

**Рамки.** Приложение «Текстовый редактор».

**Уровень.** Задача, определённая пользователем.

**Основной исполнитель.** Пользователь.

### Заинтересованные лица и их требования

- **Пользователь.** Хочет автоматически исправлять оформление текста: лишние пробелы и их расположение относительно знаков препинания. Смысл текста и структура документа должны сохраняться.

### Предусловия

Редактор запущен. Пользователем открыт или создан текстовый документ.

### Результаты (постусловия)

Текст отформатирован и отображён пользователю. Изменения находятся в контексте документа; файл на диске не изменён.

### Основной успешный сценарий

1. Пользователь вызывает автоформатирование документа.
2. Система обрабатывает текст по правилам типографического оформления.
3. Система заменяет содержимое документа отформатированным текстом.
4. Система отображает результат пользователю.

### Расширения (альтернативные потоки)

**2а. Текст не требует изменений.**

1. Система оставляет текст без изменений и сообщает об этом пользователю.
2. Сценарий завершается.

**2б. Не удалось выполнить форматирование.**

1. Система сообщает об ошибке. Исходный текст остаётся без изменений.
2. Пользователь может повторить форматирование.

**2в. Отдельный участок нельзя однозначно отформатировать.**

1. Система оставляет этот участок без изменений и обрабатывает остальные.
2. Выполнение продолжается с шага 3; если изменений нет, применяется расширение 2а.

**4а. Пользователь отменяет форматирование.**

1. Пользователь вызывает отмену последнего изменения.
2. Система восстанавливает прежний текст и отображает его пользователю.

### Специальные требования

- Форматирование относится к оформлению текста, а не к исправлению орфографии или проверке синтаксиса Typst.
- Преобразования не должны менять смысл текста, удалять значимые символы или нарушать структуру документа.
- Результат должен быть доступен для отмены.
- Запись на диск выполняется по отдельной команде из прецедента [«Управление документами»](../document_operations/document_operations.md).

### Список технологий и типов данных

- Текст документа — строка.
- Набор правил типографического оформления.
- Интерфейс `Formatter` и его реализация `TextFormatter`.

### Частота использования

По запросу пользователя в процессе редактирования документа.
