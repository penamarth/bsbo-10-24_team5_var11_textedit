
# Прецедент «Автоформатирование документа»

**Рамки.** Приложение «Текстовый редактор».

**Уровень.** Задача, определённая пользователем.

**Основной исполнитель.** Пользователь.

### Заинтересованные лица и их требования

- **Пользователь.** Хочет автоматически исправлять ошибки пунктуационного и типографического оформления текста, например лишние пробелы, неправильное расположение пробелов относительно знаков препинания и другие нарушения правил оформления.
- **Средство форматирования текста.** Получает содержимое документа и выполняет его преобразование в соответствии с установленными правилами форматирования.

### Предусловия

Текстовый редактор запущен. Пользователем открыт или создан текстовый документ.

### Результаты (Постусловия)

- Текст документа обработан модулем форматирования.
- Обнаруженные нарушения правил оформления исправлены.
- Отформатированное содержимое сохранено в контексте документа.
- Изменения отражены в контексте редактора и отображены пользователю.

### Основной успешный сценарий

1. Пользователь вызывает функцию автоматического форматирования документа;
2. Система получает актуальное содержимое контекста документа из контекста редактора;
3. Система передаёт содержимое документа модулю форматирования текста;
4. Модуль форматирования анализирует текст документа на наличие нарушений правил пунктуационного и типографического оформления;
5. Модуль определяет необходимые изменения текста, например удаление повторяющихся пробелов, удаление пробелов перед знаками препинания и добавление отсутствующих пробелов после них;
6. Модуль выполняет преобразование текста в соответствии с установленными правилами форматирования;
7. Система получает от модуля форматирования преобразованный текст;
8. Система обновляет содержимое контекста документа, заменяя исходный текст отформатированным;
9. Система обновляет контекст редактора, фиксируя изменённое состояние документа;
10. Модуль пользовательского интерфейса подхватывает изменение контекста редактора и отображает пользователю отформатированный текст;
11. Пользователь просматривает результат форматирования;
12. Пользователь продолжает редактирование документа или вызывает функцию его сохранения;
13. При сохранении документа система передаёт актуальное содержимое контекста документа модулю взаимодействия с файловой системой ОС;
14. Модуль взаимодействия с ОС выполняет запись отформатированного содержимого документа в файл;
15. Система обновляет контекст редактора, фиксируя сохранённое состояние документа.

### Расширения (или альтернативные потоки)

**4а. Нарушения правил форматирования не обнаружены.**

1. Модуль форматирования определяет, что текст соответствует установленным правилам.
2. Система оставляет содержимое контекста документа без изменений.
3. Модуль пользовательского интерфейса сохраняет текущее отображение документа.
4. Пользователь продолжает работу с документом.

**4б. Не удалось выполнить анализ текста.**

1. Модуль форматирования возвращает сообщение об ошибке.
2. Система обновляет контекст редактора, сохраняя информацию об ошибке.
3. Модуль пользовательского интерфейса уведомляет пользователя о невозможности форматирования.
4. Исходное содержимое контекста документа остаётся без изменений.

**6а. Для некоторых участков текста невозможно однозначно определить корректное форматирование.**

1. Модуль форматирования оставляет неоднозначные участки текста без изменений.
2. Модуль продолжает обработку остальных участков документа.
3. Система получает результат форматирования.
4. Выполнение продолжается с шага 8.

**11а. Пользователь хочет отменить выполненное форматирование.**

1. Пользователь вызывает функцию отмены последнего изменения.
2. Система восстанавливает предыдущее содержимое контекста документа.
3. Система обновляет контекст редактора.
4. Модуль пользовательского интерфейса отображает восстановленный текст.

**12а. Пользователь продолжает редактирование без сохранения.**

1. Пользователь вносит изменения в текст документа.
2. Система обновляет содержимое контекста документа и контекст редактора.
3. Модуль пользовательского интерфейса динамически отображает изменения.
4. Результат форматирования и последующие изменения остаются в оперативной памяти до сохранения документа.

**14а. Не удалось сохранить отформатированный документ.**

1. Модуль взаимодействия с ОС возвращает сообщение об ошибке записи.
2. Модуль пользовательского интерфейса отображает уведомление пользователю.
3. Отформатированное содержимое остаётся в контексте документа.
4. Пользователь может повторить сохранение.

### Специальные требования

- Форматирование должно выполняться независимо от формата документа, если из него возможно получить текст для обработки.
- Модуль форматирования должен работать с общими правилами оформления текста, а не исключительно с синтаксисом Typst.
- Форматирование должно устранять определённые правилами нарушения, в том числе повторяющиеся пробелы и неправильное расположение пробелов относительно знаков препинания.
- Преобразование текста не должно изменять его смысловое содержание.
- Обработка текста не должна приводить к удалению значимых символов или нарушению структуры документа.
- Изменения первоначально должны сохраняться в контексте редактора без немедленной записи в файловую систему.
- Пользователь должен иметь возможность отменить результат форматирования.

### Список технологий и типов данных

- Модуль считывания взаимодействия пользователя с системой.
- Самостоятельный модуль форматирования текста.
- Модуль отображения состояния редактора пользователю.
- Модуль взаимодействия с файловой системой через API операционной системы.
- Правила форматирования текста.

### Частота использования

По запросу пользователя в процессе редактирования документа.

### Открытые вопросы

- Какие правила пунктуационного и типографического оформления должны поддерживаться?
- Нужно ли учитывать особенности пунктуации разных естественных языков?
- Должен ли пользователь иметь возможность настраивать правила форматирования?
- Необходимо ли поддерживать форматирование отдельных выделенных фрагментов текста?
- Как определять участки документа, в которых пробелы и знаки препинания имеют специальное значение и не должны изменяться?
- Должно ли форматирование выполняться автоматически или только по запросу пользователя?
