# Описание системных операций прецедента «Линтинг документа»

Контракты описывают системные операции — события, которые пользователь инициирует через открытый интерфейс системы, рассматриваемой как «чёрный ящик». Постусловия фиксируют изменения состояния: создание экземпляров, формирование ассоциаций, модификацию атрибутов.

## Операция: lintDocument()

**Ссылки:** прецедент [«Линтинг документа»](document_linting.md), шаги 1–2.

**Предусловия:** в контексте редактора есть активный открытый или созданный документ.

**Постусловия успешного выполнения:**

- Создан экземпляр `result` класса `LintResult` (создание экземпляра).
- Экземпляр `result` связан с текущим документом (формирование ассоциации).
- Для каждой найденной ошибки создан экземпляр `LintError` с атрибутами `start`, `end`, `word`, `message`, `suggestions`; позиции переведены в координаты исходного документа (модификация атрибутов).
- Содержимое документа не изменено; файл на диске не изменён.

## Операция: selectError(position)

**Ссылки:** прецедент [«Линтинг документа»](document_linting.md), шаг 3.

**Предусловия:** проверка выполнена, в документе сохранена непустая диагностика.

**Постусловия успешного выполнения:**

- Возвращён экземпляр `LintError`, соответствующий позиции `position`, вместе с вариантами исправления.
- Состояние документа и диагностики не изменено (операция только читает данные).

## Операция: applyFix(errorIndex, suggestion)

**Ссылки:** прецедент [«Линтинг документа»](document_linting.md), шаг 4.

**Предусловия:** выбрана ошибка с индексом `errorIndex` из актуальной диагностики документа.

**Постусловия успешного выполнения:**

- Фрагмент текста документа на позициях ошибки `errorIndex` заменён значением `suggestion` (модификация атрибута содержимого).
- Предыдущее состояние текста доступно для отмены изменения.
- Диагностика документа обновлена результатом повторной проверки: устаревшие `LintError` удалены, новые созданы и связаны с документом.
- Файл на диске не изменён.

## Операция: skipError(errorIndex)

**Ссылки:** прецедент [«Линтинг документа»](document_linting.md), расширение 3а.

**Предусловия:** в документе есть непустая диагностика.

**Постусловия успешного выполнения:**

- Ошибка `errorIndex` помечена пропущенной в текущей сессии (модификация атрибута).
- Содержимое документа не изменено.
