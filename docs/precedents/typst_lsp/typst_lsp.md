
# Прецедент «Интеллектуальная поддержка языка Typst»

**Рамки.** Приложение «Текстовый редактор».

**Уровень.** Задача, определённая пользователем.

**Основной исполнитель.** Пользователь.

**Вспомогательный исполнитель.** Typst Language Server.

### Заинтересованные лица и их требования

- **Пользователь.** Хочет получать подсказки о функциях и конструкциях языка Typst, а также использовать автоматическое дополнение исходного кода для ускорения редактирования документа.
- **Typst Language Server.** Получает информацию о состоянии Typst-документа и запросы на интеллектуальную обработку кода, возвращает соответствующие подсказки и предложения.

### Предусловия

Текстовый редактор запущен. Пользователем открыт или создан Typst-документ. Средство интеллектуальной поддержки языка доступно.

### Результаты (Постусловия)

- Пользователю предоставлены подсказки или варианты автодополнения Typst-кода.
- При выборе автодополнения содержимое документа изменено.
- Изменения отражены в контексте редактора.
- Пользователю отображено актуальное содержимое документа.

### Основной успешный сценарий

1. Пользователь начинает редактировать исходный текст Typst-документа;
2. Система изменяет содержимое контекста документа и обновляет контекст редактора;
3. Модуль пользовательского интерфейса реагирует на изменение контекста и отображает введённый текст;
4. Система передаёт информацию об актуальном состоянии документа внешнему средству интеллектуальной поддержки языка Typst;
5. Пользователь вызывает функцию автодополнения исходного кода;
6. Система формирует запрос на получение вариантов автодополнения с учётом содержимого документа и текущего положения курсора;
7. Внешнее средство интеллектуальной поддержки обрабатывает запрос и возвращает доступные варианты автодополнения;
8. Система обновляет контекст редактора, сохраняя полученные предложения;
9. Модуль пользовательского интерфейса подхватывает изменение контекста и отображает список возможных дополнений;
10. Пользователь выбирает подходящий вариант автодополнения;
11. Система применяет выбранное дополнение к контексту документа и обновляет контекст редактора;
12. Модуль пользовательского интерфейса динамически отображает изменённый исходный текст;
13. Система передаёт информацию об изменении документа внешнему средству интеллектуальной поддержки для актуализации его состояния.

### Расширения (или альтернативные потоки)

**5а. Пользователь запрашивает подсказку по функции языка Typst.**

1. Пользователь устанавливает курсор на интересующую его функцию и вызывает получение подсказки.
2. Система формирует запрос на получение информации о выбранной функции.
3. Внешнее средство интеллектуальной поддержки возвращает информацию о функции.
4. Система обновляет контекст редактора, сохраняя полученную информацию.
5. Модуль пользовательского интерфейса отображает описание функции.
6. Содержимое контекста документа остаётся без изменений.
7. Выполнение возвращается к шагу 1.

**7а. Подходящие варианты автодополнения не найдены.**

1. Внешнее средство возвращает пустой результат.
2. Система обновляет контекст редактора.
3. Модуль пользовательского интерфейса не отображает список предложений.
4. Пользователь продолжает самостоятельное редактирование документа.

**7б. Внешнее средство интеллектуальной поддержки недоступно.**

1. Система получает информацию об ошибке взаимодействия.
2. Система обновляет контекст редактора, сохраняя информацию об ошибке.
3. Модуль пользовательского интерфейса уведомляет пользователя о недоступности интеллектуальной поддержки.
4. Пользователь может продолжить редактирование документа без подсказок и автодополнения.

**10а. Пользователь отказывается от предложенного автодополнения.**

1. Пользователь закрывает список предложений.
2. Система обновляет контекст редактора, удаляя неактуальные предложения.
3. Содержимое контекста документа остаётся без изменений.
4. Выполнение возвращается к шагу 1.

### Специальные требования

- Предложения должны соответствовать актуальному содержимому документа.
- Получение подсказок не должно блокировать процесс редактирования.
- Отображение подсказок не должно приводить к изменению текста документа.
- Автодополнение должно применяться только после соответствующего действия пользователя.
- Недоступность внешнего средства интеллектуальной поддержки не должна препятствовать основным операциям редактирования.

### Список технологий и типов данных

- Модуль считывания взаимодействия пользователя с системой.
- Модуль взаимодействия с внешним средством интеллектуальной поддержки языка Typst.
- Модуль отображения состояния редактора пользователю.
- Typst Language Server - внешнее средство интеллектуальной поддержки языка.

### Частота использования

Регулярно в процессе редактирования Typst-кода.

### Открытые вопросы

- Должны ли варианты автодополнения появляться автоматически при вводе текста или только по запросу пользователя?
- Какую информацию необходимо отображать в подсказках по функциям?
- Как обрабатывать запросы, ответы на которые становятся неактуальными вследствие дальнейшего редактирования документа?
- Должна ли система поддерживать несколько средств интеллектуальной поддержки?
